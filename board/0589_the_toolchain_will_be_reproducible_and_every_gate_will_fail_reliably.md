Status: open | Priority: P0 | Reviewed: 2026-09-22

## Current evidence

The review repairs test discovery, redundant builds, generator-check mutation and swallowed analyzer exits. See README for measured make/test/lint outcomes. The full audit checked 167 handwritten translation units: 152 failed and 1,009 unique diagnostics were reported before repairing three missing direct includes. Doxygen emitted 1,444 warning lines after the existing recursive-class exception (baseline 0): 743 are undocumented declarations, 92 report an unclosed `<tt>` tag, and `include/runtime/Table.h` alone has 231 warning lines, including mismatched `\param` and `\return` contracts. The largest groups were missing/direct includes (292), const methods (137), literal origins (90), designated initialization (73) and public state (62). The existing silent-place counter is also 60 against baseline 13; the review adds no suppressions. These counts are findings, not permitted baselines. Default builds still compile the generated slice and all gates; CMake includes all tiers in every gate. The review separates the generated recursion-warning exception from runtime flags. The latest full slice rebuild took 1,030 s for 14,209 sources; a following `make test JOBS=6` was green with 69 cases and no recompilation. `TestRunner.h` was a direct PCH input even though generated test sources include it explicitly. Removing that PCH edge is under frozen-snapshot verification. `make verify-start` now freezes tracked, untracked and generated inputs into a Git worktree, checks a source digest, and runs long checks there; the short help target passed and a nonexistent target was reported red.

## Implementation for Sol

The integration verifier now preserves a serialized build lane at `build/verify/lane/source`. Each run retains its immutable source archive and SHA-256 identity; the lane copies only changed inputs and verifies the same digest before building. Its first implementation used `git checkout -f`, which rewrote identical tracked files and discarded incremental compilation. The lane now skips Git operations on the same HEAD and uses `git reset --mixed` for a changed HEAD, leaving the worktree for byte-aware synchronization. Four consecutive `help` snapshots passed; the last two preserved the nanosecond mtime of an unchanged public header. A fixture proves unchanged source mtimes and compiled objects survive synchronization while changed and removed inputs are corrected. `make verify-start` and `make verify` use the lane by default. The full `all test gcc ut` snapshot started before this change and still uses its independent cold build.

After the lane changes, `make test JOBS=2` completed 71/71 gates with no rebuild, and `python3 test/toolchain.py` completed 30/30 negative controls. A running-lane fixture now proves a second lane start is refused. The broad lint gate remains red and incomplete; these targeted checks do not replace it.

Snapshot source hashing now excludes Python bytecode caches, and copying/synchronization removes them from the frozen source. A fifth real `help` snapshot passed with the changed verifier and kept the same public-header mtime; the fixture also checks stale cache removal.

After the exploratory four-source slice expansion was removed because it exposed real generic compiler gaps, `make JOBS=6` restored the original slice and passed, followed by `make test JOBS=2` at 71/71 and a no-op `make JOBS=6` in 2.2 s. The attempted expansion is recorded under WI 0038 and did not enter the green slice baseline.

The first local `make` after removing `TestRunner.h` from the PCH and adding four generated procedure sources reconfigured CMake and scheduled 931 Unity objects; this run cannot attribute the whole fanout to the slice additions alone. The existing app/module rank key limits cross-module movement but still shifts every later group within each touched module. Append new slice entries until the group key becomes stable under insertion. A bounded content-addressed grouping (split only an overfull hash bucket) is the preferred replacement; gate that adding one source recompiles only its own bucket and leaves all other generated Unity files byte-identical.
